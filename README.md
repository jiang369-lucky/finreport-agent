# 知报：中文财报研究 Agent

面向个人作品集的本地研究工作台。知识与技术边界为 **2025-08-31（北京时间）**，运行时使用固定历史模型，不使用 2025 年 10 月才推出的 Agent Skills / SKILL.md 标准。

## 快速启动

项目已附中文财报与原 SQLite 数据文件；当前应用后端已改用 PostgreSQL。数据库迁移只会在你之后执行部署脚本时运行，本次没有启动服务或迁移数据。

1. 执行 .\setup.ps1，安装新驱动并生成 PostgreSQL 本地配置。
2. 编辑根目录 .env，填写 DASHSCOPE_API_KEY；未填密钥时可用证据检索模式。
3. 之后需要部署时，确保 Docker Desktop 已运行，执行 .\start-db.ps1 初始化数据库并迁移旧数据，再执行 .\start.ps1。
4. 浏览器访问 http://127.0.0.1:8765 。

也提供应用和数据库一起运行的 Docker Compose 配置，见 docs/POSTGRESQL.md。

默认模型为 qwen3-235b-a22b-instruct-2507，通过通义千问兼容接口调用。模型在 2025 年 7 月发布。你的账户需有该固定版本的调用权限。选择与密钥地域一致的 LLM_BASE_URL；修改 .env 后重启服务。

没有配置密钥也能使用“证据检索”模式，界面明确标记该模式尚未调用大模型。正式 Agent 模式不会自动退化成模拟答案。

新机器需要 Python 3.11，先执行 setup.ps1 安装 requirements.lock。setup.ps1 会使用 pip 25.2 和带哈希的完整依赖锁。请勿直接安装各库最新版本。

## 数据规模与来源

- 10 家公司：德赛电池、中兴通讯、格力电器、京东方A、大族激光、海康威视、立讯精密、比亚迪、汇川技术、欣旺达。
- 每家公司 2022/2023/2024 年年报及 2025 年半年报，共 40 份。
- 共 9,425 个原始 PDF 页面、28,143 个检索片段，原始 PDF 共 237,287,404 字节。
- 报告均来自巨潮资讯，最晚披露日为 2025-08-30。
- data/manifest.json 保存每份报告的原始 URL、披露日期、公告 ID、SHA256、文件大小和本次抓取时间。
- 抓取时间是当前实际下载时间；截止日表示资料当时已经公开。不能把报告年度当作披露日期，也不能把今天的修订文件当作当时原件。
- 网站公开披露资料作为研究语料，不意味着拥有全部内容的再分发或商业授权。公开仓库默认忽略 PDF 与数据库，保留采集脚本和来源清单。

数据维护：

    .venv\Scripts\python.exe -m scripts.collect_reports --limit 40
    .venv\Scripts\python.exe -m scripts.ingest_reports
    .venv\Scripts\python.exe -m scripts.rebuild_metrics

采集器在公告元数据层过滤披露日期，导入时再次检查日期、目录与文件哈希，查询工具在数据库层再次过滤 as_of。

## 实现重点

### Harness 与任务模板

finagent/harness.py 用 LangGraph 管理“模型决策 → 白名单工具 → 模型决策 → 引用检查”。包含：
- 模型轮次、工具次数、总运行时间、单工具超时、有限请求重试；
- Pydantic 参数约束，禁止执行模型生成的任意 Python 或 SQL；
- 工具输入、执行结果、耗时、token 用量和状态记录；
- 未读取证据的引用不允许进入最终结论，失败时提供一次重写机会；
- 工具预算耗尽和中断会保留归档，不伪装为成功结果。

workflows/ 下的普通文本模板实现财务指标比较、现金流分析和事实查询，统一称为“三类任务模板”。

### MCP

使用官方 mcp==1.13.1 SDK，stdio 传输，2025-06-18 协议：
- search_reports：中文 BM25 检索；
- read_report_page：读取完整原始页与单元格重建的表格行；
- get_financial_metric：提取候选指标，必须回查原文；
- calculate_metric：Decimal 计算同比、占比、差额和求和；
- finreport://catalog：原始报告资源目录；
- financial_comparison：可复用任务提示。

启动独立 MCP 服务：

    .venv\Scripts\python.exe -m finagent.mcp_server

主应用的 Agent 通过真实官方 MCP ClientSession 调用财报工具，不绕过协议直接假装调用。MCP 子进程不接收模型服务密钥。

### 会话上下文：近期对话与早期摘要

PostgreSQL 保存资料索引、会话、摘要和运行记录。使用独立 schema 隔离正式数据与回归数据；迁移脚本保留原文件并验证导入内容。部署说明见 docs/POSTGRESQL.md。

- 每次请求保留最近最多 4 轮完整问答；历史问答超过输入预算时，较早的完整轮次提前纳入摘要，不截断半轮对话，并至少保留最新一轮完整问答。
- 更早对话整理成最多 1,000 字符的文本摘要：保留最初研究问题，以及较近的早期问答关键摘录。采用轻量摘录，不额外调用模型生成摘要，也不保证覆盖全部早期细节。
- 摘要写入 PostgreSQL；续接会话时按原始问答重建，避免反复压缩摘要导致内容漂移。历史上下文的预算目标采用保守 token 估算，默认为 2,300；为了保留最新一轮，允许历史部分超过该目标，模型总输入仍受硬性预算限制。
- 模型上下文由系统规则、早期摘要、近期完整问答、当前问题和本轮工具交互构成；不加入独立长期记忆或跨会话笔记召回。
- 摘要仅帮助续接话题，财务数值与引用必须以本轮检索到的原始证据为准。
- 当前研究公司从本会话最近一轮结果恢复，支持“那它上一年呢”这类追问。不同会话隔离，收紧 as_of 时排除较晚轮次。
- 完整问答和工具结果仍持久化供用户回查；工具归档只用于审计界面，不再作为模型的回取工具。
- 本轮工具交互保留原始消息。总输入超预算时返回明确提示，要求缩小研究范围，不再实施多层工具消息压缩。
- 老版本数据库中的 memories 表不再使用，也不自动删除其中的旧记录。新版不再创建这张表。旧结构化摘要会按原始问答重建。

### 检索、表格与计算

中文分词 BM25 + 公司/报告期/披露日过滤 + 指标候选索引。模型可改写查询和多轮取证。当前主线使用这一可本地复现的检索方案。

PDF 中跨行金额按检测出的单元格合并，保留列边界；季度指标不误标为全年值；重述表格中的往年列不自动猜测。提取失败时返回缺失和原文检索提示。数字计算必须使用明确单位与来源，负基数同比给出计算约定。

## 验证与评测

    .venv\Scripts\python.exe -m unittest tests.test_core -v
    .venv\Scripts\python.exe -m scripts.mcp_probe
    .venv\Scripts\python.exe -m scripts.model_probe

前两条需要 PostgreSQL 已部署，不调用付费模型。测试使用独立 finagent_test schema。第三条会使用你自己的通义千问密钥。本次按要求未执行数据库运行验证。

tests/test_core.py 检查日期过滤、列间数字拼接、季度口径、重述、Decimal、近期完整问答、早期摘要长度与持久化、会话隔离、旧摘要兼容、四项工具白名单、工具预算和引用修复。
使用 scripted model 的 harness 验证只检查编排和约束，不能当作真实大模型准确率。真实模型的正确率、成本和表现应在密钥配置后另行测量。

## 历史依赖审计

## 目录

- finagent/：运行控制、数据、记忆、模型、MCP 与 HTTP API。
- workflows/：截止日前技术可实现的任务模板。
- web/：无需外部 CDN 的中文研究工作台。
- scripts/：采集、索引、审计、验证和评测入口。
- tests/：不消耗模型额度的可靠性验证。
- data/raw/：原始 PDF；data/research.sqlite3：只读迁移来源，正式索引、会话、摘要和运行记录保存在 PostgreSQL。

- docs/：技术边界、架构说明与项目交付记录。
- work/：检查、渲染和临时运行记录。

## 已知限制

当前为单用户本地应用，监听 127.0.0.1。证据引用检查验证来源存在与是否读过，不能自动证明每个自然语言判断都与原文语义一致。复杂表格、重述和口径差异仍需回查；扫描版财报未加入 OCR。
固定历史模型可能被服务商下线，不能悄悄替换为更晚模型；可改用白名单内其他历史快照，或本地部署当时发布的 Qwen3-8B 并锁定权重 revision。

本次具体交付状态见 docs/DELIVERY.md，机器可读验证记录见 docs/validation-report.json。评测使用说明见 eval/README.md。
